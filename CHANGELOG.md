# Changelog

## 0.2.0 - 2026-10-30

- Вход в нейросеть описан по официальной документации Hermes: ChatGPT/Codex или Nous Portal по одноразовому коду, API-ключ с лимитом расходов, подписка Claude только на тарифе Max с докупленными кредитами.
- В конце установки агент сообщает о постоянном доступе к серверу и убирает его без договорённости о поддержке. Новая строка в итоговом отчёте.
- Новая фраза-запуск «установи Hermes моему клиенту».
- Telegram ID клиента запрашивается вместе с доступами, токен бота - перед подключением Telegram.
- Разведены роли: «владелец» - тот, кто ставит задачу агенту, «клиент» - хозяин сервера и будущего агента.
- В итог для клиента добавлено, что делать, если агент не отвечает, и как сменить токен бота.
