# Install Hermes Client

Скилл для личного агента (Claude Code или Codex): ставит клиенту [Hermes Agent](https://github.com/NousResearch/hermes-agent) на новый сервер. Терминал открывать не нужно. Вы пишете агенту обычным сообщением, а техническую работу он делает сам.

## Как это выглядит

Вы пишете своему агенту:

> Установи Hermes моему клиенту.
> IP: ... Логин: ... Временный пароль: ... Telegram ID клиента: ...

Дальше скилл ведёт агента по шагам:

1. Сначала только проверяет сервер. Ничего не ставит.
2. Сообщает, подходит ли сервер и что на нём уже работает.
3. Ждёт вашего подтверждения.
4. Берёт Hermes только из официального репозитория.
5. Сам выполняет установку.
6. Помогает подключить нейросеть и Telegram.
7. Проверяет запуск и работу агента.
8. Настраивает автоматический запуск после перезагрузки.
9. Создаёт резервную копию.
10. Напоминает клиенту поменять временный пароль сервера.

## Что понадобится

- Свой агент на Claude Code или Codex, который умеет подключаться к серверам.
- Новый сервер клиента, арендованный на его аккаунт: IP, логин и временный пароль.
- Telegram-бот клиента, созданный в @BotFather, и числовой Telegram ID клиента.
- Нейросеть клиента. Основной вариант - подписка ChatGPT (Codex) со входом по одноразовому коду. Ещё подходят Nous Portal или API-ключ. Подписка Claude в Hermes работает только на тарифе Max с докупленными дополнительными кредитами.

## Как подключить скилл без терминала

Отправьте своему агенту сообщение:

> Установи себе навык из https://github.com/mcdenil-skills/install-hermes-client - файл SKILL.md сохрани как свой личный навык install-hermes-client.

Если агент сделан через Agent Factory, после этого нажмите `/reset`, чтобы он перечитал навыки.

Можно и так: скачайте `SKILL.md` и отправьте файл агенту с той же просьбой.

Если работаете в терминале, положите `SKILL.md` в папку `~/.claude/skills/install-hermes-client/` для Claude Code или `~/.agents/skills/install-hermes-client/` для Codex.

## Безопасность

- Временный пароль сервера попадает в переписку с агентом. Удаление сообщения не гарантирует, что пароль исчез из всех журналов. Поэтому пароль должен быть временным и уникальным.
- После установки клиент обязательно меняет пароль в панели хостинга и никому не сообщает новый.
- Скилл не повторяет пароль и токен бота в ответах и не сохраняет их в память.
- В конце агент сообщает, остался ли у него постоянный доступ к серверу, и убирает его, если с клиентом нет договорённости о поддержке.
- Резервная копия Hermes содержит пароли и ключи агента. Её не пересылают в чат.
- Скилл не удаляет и не трогает другие проекты на сервере. Если сервер не пустой, агент остановится и спросит.
